    \section{Introducción}

        Este es un programa en JavaFX en el que la principal tarea es jugar con los hilos (Threads).

        \vspace{0.3cm}
        La principal novedad en este programa es la implementación de un patrón productor-consumidor utilizando hilos y sincronización en Java. Para ello se han implementado los métodos \textbf{wait()} y \textbf{notify()} para gestionar el acceso concurrente a un buffer compartido entre productores (baristas) y consumidores (camareros).

        \vspace{0.3cm}
        \begin{figure}[H]
            \centering
            \includegraphics[width=0.7\textwidth]{images/modelo.png}
        \end{figure}

        \vspace{0.3cm}
        En resumen, el barista produce cafés y los coloca en una mesa (buffer) con capacidad limitada. Si la mesa está llena, el barista espera hasta que un camarero recoja un café. Por otro lado, el camarero consume cafés de la mesa. Si no hay cafés disponibles, el camarero espera hasta que el barista prepare más.
        
        \vspace{0.3cm}
        Esta sincronización asegura que no haya condiciones de carrera y que los productores y consumidores operen de manera coordinada.

    \section{Modelo}

    \subsection{Introducción del modelo}
    
        El modelo implementa el patrón productor-consumidor utilizando hilos en Java. En este caso, el barista actúa como productor que prepara cafés y los coloca en una mesa (buffer) con capacidad limitada. El camarero es el consumidor que recoge los cafés de la mesa para servirlos a los clientes.

        \subsubsection{Buffer.java}

            Clase compartida entre productores y consumidores.
            \begin{itemize}
                \item \texttt{contador\_de\_cafes}: Número actual de cafés en la mesa (capacidad máxima: 3)
                \item \texttt{put()}: Método sincronizado para que el Barista deje un café. Si la mesa está llena, espera con \texttt{wait()}
                \item \texttt{get()}: Método sincronizado para que el Camarero recoja un café. Si no hay cafés, espera con \texttt{wait()}
                \item Usa \texttt{notifyAll()} para despertar hilos en espera cuando cambia el estado del buffer
            \end{itemize}

        \subsubsection{Barista.java (Productor)}

            Thread que representa al barista que prepara los cafés.
            \begin{itemize}
                \item Extiende \texttt{Thread} para ejecutarse de forma concurrente
                \item Realiza 35 iteraciones preparando cafés
                \item Llama a \texttt{buffer.put()} para dejar cada café en la mesa
                \item Simula tiempo de preparación aleatorio (0-500ms) con \texttt{Thread.sleep()}
                \item Imprime mensajes de estado en consola
            \end{itemize}

        \subsubsection{Camarero.java (Consumidor)}

            Thread que representa al camarero que sirve los cafés a los clientes.
            \begin{itemize}
                \item Extiende \texttt{Thread} para ejecutarse de forma concurrente
                \item Realiza 35 iteraciones sirviendo cafés
                \item Llama a \texttt{buffer.get()} para recoger cada café de la mesa
                \item Simula tiempo de servicio aleatorio (0-500ms) con \texttt{Thread.sleep()}
                \item Imprime mensajes de estado en consola
            \end{itemize}
